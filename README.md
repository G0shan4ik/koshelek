# Кошелёк — счётчик расходов и доходов

PWA-приложение для личного учёта финансов: работает на ПК и телефоне, данные синхронизируются через Supabase, сайт бесплатно хостится на GitHub Pages.

## Возможности

- Доходы и расходы с категориями, иконками, цветами и заметками
- Обзор: общий баланс, итоги месяца, диаграмма расходов, последние операции
- История: фильтры по месяцу, типу, категории и поиск по заметкам
- Отчёты: динамика за 6 месяцев, разбивка расходов и доходов по категориям
- Свои категории (иконка + цвет), валюта на выбор (₽, $, €, Br и др.)
- Мультивалютность: операции и пополнения в любой валюте (курсы НБРБ обновляются автоматически, курс можно задать вручную), всё пересчитывается в базовую валюту; отчёт «По валютам» и фильтр по валюте в истории
- Вход по email и паролю, у каждого пользователя свои данные (Row Level Security)
- Экспорт в CSV (для Excel) и JSON-резервная копия, импорт из копии
- Оффлайн-режим: без сети показываются последние сохранённые данные
- Установка на телефон как обычное приложение (PWA)
- Без настроенного Supabase работает локально: данные хранятся в браузере

## Локальная разработка

```bash
npm install
npm run dev
```

Без `.env` приложение стартует в локальном режиме (данные в браузере) — можно пользоваться сразу.

## Подключение облака (Supabase) — ~10 минут

1. Зарегистрируйся на [supabase.com](https://supabase.com) и создай проект (бесплатный план).
2. Открой **SQL Editor** и выполни целиком содержимое файла `supabase/schema.sql` — создаст таблицы и политики безопасности.
3. Открой **Authentication → Providers → Email** и выключи **Confirm email** (иначе придётся подтверждать почту письмами).
4. Скопируй ключи: **Project Settings → API** → `Project URL` и `anon public key`.
5. Создай файл `.env.local` в корне проекта:

   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```

6. `npm run dev` — теперь приложение в облачном режиме: зарегистрируйся и пользуйся.

> `anon`-ключ публичный по замыслу Supabase: доступ к данным защищают политики RLS из schema.sql — каждый пользователь видит только свои записи.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub (название латиницей, например `koshelek`) и запушь туда этот проект.
2. В настройках репозитория: **Settings → Secrets and variables → Actions** добавь секреты:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
3. Включи Pages: **Settings → Pages → Source: GitHub Actions**.
4. Каждый push в `main` собирает и публикует сайт (workflow `.github/workflows/deploy.yml`). Адрес: `https://<твой-логин>.github.io/<имя-репозитория>/`.

## Защита от «усыпания» Supabase

Бесплатный проект Supabase засыпает после ~7 дней без запросов. Workflow `.github/workflows/keep-awake.yml` раз в сутки пингует базу через GitHub Actions, чтобы проект не засыпал. Если репозиторий бездействует 60 дней, GitHub отключает scheduled-задачи — тогда просто запусти workflow вручную (**Actions → Keep Supabase awake → Run workflow**) или открой приложение.

## Установка на телефон

Открой адрес сайта в браузере телефона и выбери «Установить приложение» / «На главный экран» (Chrome/Safari). Приложение работает оффлайн для просмотра, а при появлении сети данные синхронизируются.

## Структура

- `src/lib` — слой данных: единый API с двумя реализациями (localStorage / Supabase)
- `src/components` — экраны и виджеты (обзор, история, отчёты, настройки, модалки)
- `src/context/AppContext.tsx` — состояние приложения: сессия, операции, категории, оффлайн-кэш
- `supabase/schema.sql` — таблицы и политики безопасности
- `.github/workflows` — автодеплой на Pages и ежедневный пинг Supabase
- `scripts/gen-icons.ps1` — генерация иконок PWA
